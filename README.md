# Tic-Tac-Toe

A web-based interactive **Tic-Tac-Toe game** built with **React**. Play against a friend in a classic 3×3 grid with turn-based gameplay and win/tie detection.

## Overview

This project implements a classic **Tic-Tac-Toe game**:

- Two players can play on a 3×3 board  
- Turn-based gameplay with automatic player switching  
- Real-time win and tie detection
- Return to a previous step
- Reset / restart the game at any time

## Getting Started

```bash

git clone https://github.com/jKnaebe/tic-tac-toe.git
cd tic-tac-toe

# Install dependencies
npm install

# Start the dev Server
npm start
```
